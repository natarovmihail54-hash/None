## Задача: онлайн магазин товаров
Написать консольную программу на питон, которая позволяет делать покупки разных товаров с учётом баланса

## План
 - Создай каталог товаров в магазине;
 - При вводе Start отображается каталог;
 - добавить функцию покупки, при которой будет сниматься баланс;
 - при балансе = 0, выводится предупреждение "ваш баланс = 0".
 - при выходе баланса меньше 0 выводится ошибка
при запуске программы отобразить несколько товаров, например:

   - 1)Телевизор - 50000
   - 2)Телефон - 30000
   - 3)Компьютер - 100000


## При успешном выполнении ТЗ полагается бесплатное пополнение баланса
